# Дизайн и анализ A/B-теста с применением CUPED (на примере платформы Marketpele)

## Описание проекта
Список объявлений платформы **Marketpele** содержит «органические» и «платные» элементы:
* **Платные элементы** - рекламные объявления, при нажатии на которые пользователи переходят на страницу рекламодателя и приносят доход платформе.
* **Органические элементы** - контент издателя, при нажатии на которые пользователи переходят на другую статью от того же автора.

**Задача:** Спроектировать и проанализировать A/B-тест нового порядка расположения элементов в ленте (4 рекламных блока наверху + 1 органический внизу вместо стандартной схемы 1 + 4).

**Цель теста:** Увеличить конверсию кликов (CTR) по платным и органическим элементам для роста выручки.

---

## Ключевые результаты и бизнес-решение
* **Мобильный сегмент (`mobile`, 94% выручки):** Зафиксирован разнонаправленный статистически значимый эффект (alpha = 0.025 с поправкой Бонферрони). Платный CTR вырос на **+14.67%** (p < 0.001), но органический CTR упал на **-28.35%** (p < 0.001). При этом выручка (`revenue`) значимо не изменилась (**+1.83%**, p = 0.63).
* **Десктопный сегмент (`desktop`):** На этапе дизайна выявлена нехватка мощности выборки (CUPED MDE 12.5%–14.7%). В ходе теста ни одна из метрик не преодолела порог значимости.
* **Итоговое решение:** **Отклонить изменение и сохранить контрольную версию (control).** Новая верстка вызвала эффект замещения трафика без роста выручки и создала высокий риск оттока издателей и пользователей в долгосрочной перспективе.

## Стек и методология
* **Язык и библиотеки:** Python, Pandas, NumPy, SciPy, Matplotlib, Seaborn.
* **Статистический методы и дизайн:**
  * Сегментация по платформам (`mobile` / `desktop`) и агрегация метрик на уровень пользователя (`user_id`).
  * Очистка финансовых выбросов методом IQR (фильтрация и винзоризация).
  * Снижение дисперсии с помощью **CUPED** (позволило уменьшить порог MDE на 25–37%).
  * Контроль множественного тестирования (**поправка Бонферрони**, alpha = 0.025).
  * Валидация дизайна через **A/A и A/B симуляции** (10 000 итераций), проверка перекоса трафика (**тест хи-квадрат** ) и оценка эффектов **двусторонним t-тестом Уэлча**.

## Описание данных
1. **`user_activity_data.csv`** — исторические логи активности 3 000 пользователей за 56 дней (предэкспериментальный период):
   * `date` — дата;
   * `user_id` — идентификатор пользователя;
   * `device` — тип устройства (`mobile` / `desktop`);
   * `pages_viewed` — количество просмотров страниц;
   * `paid_clicks` — клики по рекламным объявлениям;
   * `organic_clicks` — клики по органическим ссылкам;
   * `revenue` — доход от действий пользователя.

2. **`experiment_data.csv`** — агрегированные итоги A/B-теста:
   * `user_id`, `device`, `pages_viewed`, `paid_clicks`, `organic_clicks`, `revenue`;
   * `ctr_paid` — CTR по рекламным объявлениям;
   * `ctr_organic` — CTR по органическим ссылкам;
   * `group` — группа пользователя в эксперименте (`control` / `test`).

## Структура проекта
Проект состоит из 3 основных блоков:
1. **Изучение и обработка исторических данных (EDA):** проверка аномалий, сегментация платформ, очистка выбросов выручки, корреляционный анализ.
2. **Проектирование и валидация дизайна A/B-теста:** расчет размеров групп для закрытой когорты, оценка MDE до и после CUPED, проведение A/A и A/B симуляций.
3. **Статистический анализ результатов:** проверка сплитования трафика, винзоризация итоговых данных, расчет CUPED-метрик и формирование бизнес-рекомендаций.
